# Soundly 0.9 — actualización visual

1. Descargar el artefacto soundly-ios desde https://github.com/Cloud9null/Soundly/actions/runs/43665055034/artifacts/14142327680 .
2. Extraer el ZIP y localizar Soundly-unsigned.ipa.
3. Abrir esa IPA en Sideloadly y actualizar sobre Soundly usando la misma cuenta y bundle identifier. No desinstalar: al borrar la app se elimina la biblioteca privada. Requiere iOS 26+.

Now Playing presenta portada cuadrada completa, Play/Pause sobre cristal circular y controles secundarios más discretos. Con título largo o texto ampliado se conserva el desplazamiento vertical para acceder al contenido.

Personalización: Now Playing → ⋯ → Visualizer, o Settings → Appearance → Visualizer. Elegir Wave, Mirror, Bars u Orbit; Off desactiva el análisis. Probar Mirror + Rainbow o Wave + Amber. Con el visualizador visible, el icono de ajustes junto a SOURCE WAVEFORM permite cambiar estilo y color directamente.

Se usan amplitudes PCM reales del archivo, suavizadas para dibujar una envolvente. Una señal constante o muy silenciosa puede verse casi plana. El dibujo no modifica el audio ni verifica los bits del DAC. Pausa detiene el refresco continuo; Reduce Motion desactiva la interpolación animada.

Comprobar en tu iPhone portada con título largo, Play/Pause/Anterior/Siguiente, calidad/Signal Path, cola, letras, colores y volumen del sistema. Se conservan biblioteca, playlists, temas e iconos. El ZIP contiene también evidencia de pruebas; la IPA es el archivo que se carga en Sideloadly. El enlace de GitHub tiene retención temporal indicada en PHASE-9.md.
