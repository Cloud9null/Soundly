# 0.7 expansion — verified device preview

Adds asynchronous cached MPMediaItemArtwork publication for system Now Playing/Lock Screen/Control Center, guarded by current track identity and cancellation; each metadata refresh retains that artwork. A track without embedded artwork still has no fabricated album image. Physical lock-screen rendering needs device confirmation.

Audio & Playback stores a default-on bit-perfect-oriented policy. It bypasses optional EQ, requests source rate and preserves the existing compatible direct graph. Opting out allows a real five-band AVAudioUnitEQ with a -6 dB preamp and explicit processing-applied diagnostics; applying settings rebuilds at the prior position/play state. Integer-to-float conversion, native-rate mismatch and Bluetooth remain disclosed. The diagram summarizes actual API observations; detailed stages remain below. No public iOS exclusive-USB mechanism is claimed and no checkbox grants verified bits.

Playlists use local preferences without schema migration, with multiple named ordered lists, editing/removal/reorder, library selection and Soundly JSON import/export. Files contain hashes/names, no music or absolute paths. Exact file content must be imported separately on another phone; unresolved entries remain visible. M3U interoperability is not implemented. Import validation bounds file size/collection sizes, rejects invalid/duplicate entries, and never overwrites stored lists with invalid data.

Visualizer styles Off/Bars/Mirror/Orbit and Mint/Rose/Ocean use a real source PCM peak envelope decoded on a cancellable worker, bounded to about 20,000 values. They display source amplitudes near the observed playhead, before DSP, not a live render tap, FFT or measurement of the physical output. Off is default to avoid extra decode work; analysis cancels with the view/task. Nothing is allocated or analyzed in a realtime render callback.

Themes are grouped as Automatic, Light and Dark. Existing themes and library storage are retained. Added tests cover integrity override/clamping, playlist exchange/order/rejection and real PCM envelope values. Existing compilation, regression tests, EQ acoustic behavior, Lock Screen and new UI workflows must be distinguished from authored code; record actual CI results before delivering an IPA. Broader stereo/DSP/headroom, playlist UI/export-provider, visualization energy and hardware route acceptance remain necessary.
