# Soundly quick start — 0.6 refinement

Requires iOS 26 or later. Sign the unsigned device IPA using Sideloadly on your own computer, following BUILDING.md. For an update, keep the same Apple signing account and resulting bundle identifier and install over the existing app. Keep originals; deleting Soundly removes its private library, which is excluded from device backup.

1. Choose **Add Music** on Home or Settings. Select audio files or a folder. Wait for import progress to finish; completed private copies play offline. Provider files may first require a download. Automatic import skips byte-identical files.
2. Open **Library → Songs**. The list shows the filtered song total and row positions. Search locally, choose a sort/filter or browse Albums, Artists and Folders. Tap a song to start the library queue.
3. Tap the mini-player to open full-screen **Now Playing**. Use the large play/pause, previous/next and position controls. The header shows the current position in the actual queue. The star saves favorites.
4. The bottom icons are **Shuffle, Repeat, Output, Queue, More**. Repeat cycles Off → All → One. The native output picker selects available system destinations; it cannot force an unsupported DAC rate. More contains Stop. System volume controls the iOS output, not an extra app gain stage.
5. Tap the **album cover** for an artwork-only view; close with ×. Tap the **quality badge** for the live source → decoder → engine → session → route → assessment report. Expand the sheet/scroll to inspect all stages. File depth is not a measurement of the DAC output depth.
6. With a USB DAC connected, start/resume music and inspect **requested rate**, **effective session rate**, engine path and route. Equal observed rates do not establish bit identity. Float conversion is disclosed; Bluetooth is not verified PCM. A physical DAC/internal-circuit bypass cannot be forced by the app. Record actual device observations with DEVICE-ACCEPTANCE.md.
7. Choose **Settings → Library → Find duplicates → Scan library**. Review the groups and confirm removal only when satisfied. The app retains one copy per group (preferring the selected song), merges favorites/history and prunes removed queue entries. Only Soundly private copies are eligible. Different tags/encodings/masterings are intentionally preserved; this is exact-file detection, not acoustic similarity. A correct scan can find zero.
8. Choose one of twelve saved themes in **Settings → Appearance**. No account, music upload, streaming service or network permission is needed for playback.

The first device test should use a small collection with known FLAC, ALAC, WAV and AIFF samples. Check seeking, queue navigation, screen locking, interruptions, headphones/DAC disconnection and relaunch, then expand the library. Record observed results; the project does not treat a CI pass as hardware acceptance. Gapless, playlists/LRC and broader performance/accessibility work remain separate milestones.
