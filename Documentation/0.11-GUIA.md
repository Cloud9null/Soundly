# Soundly 0.11 — playlists portables

Actualiza con Sideloadly sobre Soundly existente, usando la misma cuenta y bundle identifier. No desinstales: iOS borra la biblioteca privada al hacerlo. Conserva siempre tus archivos originales.

1. Library → botón de cuadrícula → Playlists → Import playlists. Selecciona JSON de Soundly o M3U/M3U8 desde Files.
2. Primero importa la música a Soundly. El M3U solo contiene referencias; no copia archivos externos ni descarga enlaces. Revisa las coincidencias antes de pulsar Import.
3. Las referencias ambiguas o faltantes quedan en Unmatched references dentro de la playlist. Después de importar más música, pulsa Retry matching. Puedes eliminar referencias pendientes individualmente.
4. Dentro de una playlist, Export M3U8 guarda una lista UTF-8. Para usarla con otro reproductor, mantén pulsada cada pista → Share music file y guarda esos archivos junto a la lista, conservando los nombres. No se incluye música dentro del M3U.
5. Export playlists conserva todas las playlists mediante JSON, incluidas referencias pendientes. Las pistas resueltas mantienen su orden; las pendientes se guardan en una sección separada y se exportan después.

Límite de importación: 2 MiB y 20,000 referencias por lista; JSON mantiene sus límites de colección. No admite listas HLS ni reproducción de URLs. Un hash Soundly explícito que ya no existe queda pendiente en vez de enlazarse con otra canción.

Se conserva la interfaz 0.10: waveform integrado en la barra de reproducción (⋯ → Visualizer), navegación de Library desde la cuadrícula y Settings → Appearance → App Icon con Prism y los nueve alternativos. El motor de audio no cambia en esta actualización. Signal Path sigue distinguiendo fuente, conversiones observadas y salida no verificada físicamente.
