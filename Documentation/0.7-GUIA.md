# Soundly 0.7 — guía de prueba

Instalar la IPA mediante Sideloadly sobre la aplicación existente, con la misma cuenta y bundle identifier. No borrar Soundly para actualizar: su biblioteca privada se elimina al desinstalar. Mantener originales de la música.

- Portadas: reproducir una canción que sí muestre portada dentro de Soundly, bloquear el iPhone y abrir también el panel ampliado de reproducción del Centro de control. La app publica la imagen mediante MPMediaItemArtwork; confirmar su presentación real en el dispositivo. Canciones sin portada no reciben una imagen inventada.
- Audio: Settings → Audio & Playback. El modo orientado a bit-perfect viene activado por defecto y omite el EQ. Para usar los cinco controles del EQ, desactivar ese modo, habilitar Equalizer y pulsar Apply audio settings. Los cambios se aplican conservando posición/estado y modifican la señal. El preamp de −6 dB aporta margen; no garantiza ausencia de clipping.
- Signal Path: tocar el indicador de calidad. El resumen vertical muestra fuente, decodificador, motor y salida de sesión; debajo quedan los detalles. Un cambio 44.1 → 48 kHz es resampling. Cambiar Integer24 → Float32 a la misma tasa es conversión de representación, distinta de resampling. La tasa efectiva es la reportada por iOS, no una medición de bits físicos. Bluetooth y codec negociado no se inventan cuando no están expuestos.
- Playlists: Library → Playlists. Crear nombre, entrar y añadir pistas desde la biblioteca. Edit permite reordenar/eliminar. Export playlists crea un JSON de Soundly; Import playlists importa ese formato. La música no se incluye: importar por separado archivos idénticos para resolver sus hashes. No se implementó M3U/M3U8 en esta versión. Los registros no resueltos permanecen visibles.
- Visualizador: Settings → Appearance → Visualizer. Off, Bars, Mirror u Orbit; colores Mint, Rose y Ocean. Se calcula una envolvente de amplitud PCM de la fuente en un worker cancelable. El dibujo sigue la zona del playhead antes del DSP; no representa el DAC ni un espectro FFT. Activarlo implica una pasada adicional de decodificación. Off evita ese trabajo.
- Temas: el selector separa Automatic, Light y Dark.
- Iconos: Settings → Appearance → App Icon. Prism es el principal; Aurora, Pulse y Orbit son alternativas propias generadas con Core Graphics. Se usa la API oficial de iOS para cambiar el icono real; puede aparecer una confirmación del sistema. Comprobar también el resultado en la pantalla de inicio. La biblioteca no cambia.

## Uso personal de tu esposa

No necesita programar ni pagar una membresía para probar mediante Sideloadly. Conectar su iPhone a tu PC, confiar en el equipo, cargar la IPA y firmar con su propia cuenta Apple dentro de Sideloadly. Activar Developer Mode/confiar en la app si iOS lo solicita. Una cuenta gratuita requiere renovar la firma cada siete días; conservar cuenta/bundle ID y renovar sin borrar la app. Sus archivos y biblioteca son independientes. No compartir contraseñas por este chat ni incorporarlas al repositorio.

TestFlight sería más sencillo para ella a futuro: instalar TestFlight y aceptar una invitación. Antes requiere configurar la distribución del desarrollador y la revisión beta externa correspondiente; las compilaciones duran hasta 90 días. Esta entrega no es una publicación TestFlight.
